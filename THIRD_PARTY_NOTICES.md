# Third-party model notice

The optional model installed by `download_model.py` is downloaded from:

- Repository: `rarfileexe/Plant-Disease-Detector`
- URL: <https://huggingface.co/rarfileexe/Plant-Disease-Detector>
- Model card license: MIT
- Architecture: MobileNetV2
- Dataset: PlantVillage (augmented), 38 classes

The model card reports 98.75% test accuracy. That number is third-party and self-reported; Vita AI does not present it as locally verified. Run `evaluate.py` against an untouched test set to generate evidence for this installation.

The model and application are educational decision-support tools. They are not a substitute for diagnosis by a qualified agricultural professional.
